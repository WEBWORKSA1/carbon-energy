# Carbon.Energy

**Know your carbon. Cut your energy bill.** Live grid carbon intensity, an atmospheric CO₂ tracker, free footprint / solar / EV / heat-pump calculators, 220+ country profiles, guides, news and a free clean-energy quote service.

GitHub Pages (main branch, root) · Google AdSense `ca-pub-6620975821265271`.

## How it's built (two modes)
**Mode 1 — GitHub Pages / Jekyll (active now, zero setup).** Each page (`index.html`, `calculator.html`, `guides/*.html`, `country/<slug>/index.html`) is a small front-matter stub. GitHub Pages' built-in Jekyll wraps it in `_layouts/default.html` and pulls the page body from `src/` (`includes_dir: src`). Country pages render from `_data/countries.json` via `_layouts/country.html`. `sitemap.xml` and `data/countries.json` are generated by Jekyll.

**Mode 2 — self-updating static build (optional upgrade).** Copy `automation/update.yml` to `.github/workflows/update.yml` (GitHub → Add file → Create new file). The workflow runs every 6 hours: it downloads fresh Our World in Data + NOAA data and RSS news, overwrites the stubs with fully static HTML, writes richer country pages with history charts, `data/news.json` and a new sitemap. Both modes use the same assets.

## Forms
All forms post via AJAX to FormSubmit. The destination inbox is assembled in `assets/js/core.js` at runtime and never appears in HTML. **The first submission triggers a one-time activation email** from FormSubmit to the site inbox — click *Activate* once.

## Launch checklist
1. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
2. DNS for carbon.energy: A records `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; `www` CNAME → `webworksa1.github.io`. The `CNAME` file sets the custom domain; tick *Enforce HTTPS* once the certificate is issued.
3. (Recommended) Install the workflow as described in Mode 2, then Actions → *Run workflow*.
4. Google Search Console → add property → submit `https://carbon.energy/sitemap.xml`.
5. AdSense → Sites → add `carbon.energy` → request review (`ads.txt` included). Enable the Google-certified CMP for EEA/UK/CH under Privacy & messaging.
6. Optional: add PayPal / Stripe / Buy Me a Coffee / Patreon links in `CFG.pay` in `assets/js/core.js`.
